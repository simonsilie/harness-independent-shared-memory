# Store personal memory locally outside repositories and version control

Initially, memory runs on one local computer and is shared by Codex, Claude Code, and OpenCode on that computer. Store durable knowledge, temporary context, archives, and any memory database in a dedicated user data directory outside all source repositories; memory content must not be tracked in version control. Backup and restoration are in scope, while synchronization across computers is outside the initial scope; the exact data path and backup mechanism remain undecided.
