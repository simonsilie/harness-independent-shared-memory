## Smallest justified addition

The native probes [E4] establish an unavailable-inference CLI storage/keyword path and confirm full-history rows can commit and roll back with native mutations. SQLite backup preserves fixture history, but native OKF export omits it. The implemented version-3 workflow bundle—not native OKF—now passes protected logical/SQLite normal restore [E16]. E5 and E13–E18 establish unavailable-inference behavior for the exercised sqlite-vec-free paths; deployment-wide model independence remains a separate requirement. Keep the live corpus and client permissions unchanged. A failed deployment test calls for an explicit engine/requirement decision under section 8, not an implicit inference dependency.

The existing `workflow/` implementation already reuses native notes, search and the mutation transaction hook for immutable proposal-base checks, atomic acceptance/history, decisions, retry receipts, separate handovers and retrieval eligibility [E6–E18]. Reuse it and its existing bundle/importer and client runners rather than adding another store, exporter or adapter. Original recommendations to integrate those behaviors described the pre-E6 gap, not current missing code.

Protected storage and separate reviewer access are proven only for the owner-provisioned fixtures [E9, E13–E18]. A same-user facade over agent-writable files still cannot supply that boundary. No persistent workflow facade is deployed for productive use. This inventory does not justify another engine, extra clients, semantic ranking or automatic capture hooks.

Several isolated contract tests now pass; **rollout approval does not**. The former everyday-use gates, including read-only-before-capture, are superseded: current productive writes follow [ADR 0002](adr/0002-agent-proposals-with-human-approval.md) and the [client connections](client-connections.md), while the everyday-use trial became ongoing [observation review](ROADMAP.md) under ADR 0011. Assess deployment-wide model independence and any applicable active-cache path on the selected deployment separately from fixture evidence. The [section 12 alternative screening](historical-alternative-screening.md) remains the historical comparison, not a claim that the implemented controlled workflow is still absent. Retained fixture results authorize no additional mutation capability.
