# Reviewing observations from real projects

Review handover continuations, missed recall, useful defaults, reminders and
maintenance burden during ordinary work. Capture observations as work happens
and assess reproducible gaps. Keep optional owner feedback distinct from the
agent's assessment. See the [observation format](shared-memory-observations.md)
and [ADR 0011](adr/0011-real-project-use-with-ongoing-evaluation.md).

## Review findings

An initial review found a reproducible sandbox permission issue with automatic
log appends. The Codex configuration now grants write access to the dedicated
observations directory. Fresh sessions verified the fix. Keep individual
observation records and review evidence local.

Backup, restoration and export have separate verification procedures. Continue
reviewing handovers and reminders as evidence from ordinary work accumulates.
