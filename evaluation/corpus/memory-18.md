# Pilot constraints

The proposed phase 1A keeps the curated corpus in one repository, with one owner and one writer host, and exercises global read-only retrieval during real work across at least two repositories under section 13's everyday-use gate. The owner seeds 20–30 reviewed, non-sensitive records with sources and stable IDs, and indexes only accepted, currently applicable entries. Verify each client's effective tools permit only read/search; otherwise leave the unrestricted server disabled. Tool allowlists are workflow restrictions, not authorization against shell access. Agent capture, automatic lifecycle filtering, review enforcement, concurrent writes, complete revision-history portability, and multi-user authorization are deferred.
