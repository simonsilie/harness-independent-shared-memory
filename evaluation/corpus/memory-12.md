# Startup retrieval

The proposed agent workflow starts by resolving the project and searching accepted decisions and lessons. Separately inspect handovers for the current project/task and compare their branch and commit with the checkout before resuming work. Explicit tool or CLI calls remain the fallback; identical lifecycle hooks across clients are not assumed.
