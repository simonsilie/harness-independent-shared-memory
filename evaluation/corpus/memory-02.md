# Evaluate before building

The architecture proposal recommends evaluating Basic Memory in a read-only, personal recall experiment with a curated corpus before implementing a custom memory engine. Agent capture requires separate proposal-review, revision-safety, and handover-retrieval gates; recall success does not establish capture or team compliance.
